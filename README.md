# ESP32 + ULN2003 + 28BYJ-48 動作確認

ESP32 DevKitC / ESP-WROOM-32 向けの、モータ2台用PlatformIOプロジェクトです。
Arduinoフレームワークを使用し、外部ライブラリは不要です。
ビルド環境は公式Espressif32 6.12.0に固定し、依存パッケージを `.pio/packages` に保存します。
初回ビルド時はツールチェーンとArduinoフレームワークのダウンロードが必要です。
`board = esp32dev` は [PlatformIO公式のボード設定](https://docs.platformio.org/en/stable/boards/espressif32/esp32dev.html)に準拠しています。

## 配線

| ULN2003 | Motor 1 | Motor 2 |
| --- | --- | --- |
| IN1 | GPIO13 | GPIO18 |
| IN2 | GPIO14 | GPIO19 |
| IN3 | GPIO16 | GPIO21 |
| IN4 | GPIO17 | GPIO22 |

各モータをそれぞれのULN2003の5ピンコネクタへ接続し、各ドライバへ外部5Vを給電します。
外部5V・両ULN2003・ESP32のGNDは共通接続します。

## ビルド・書き込み・操作

PowerShellで、このフォルダを開いて実行します。
現在のフォルダ名にはローマ数字 `Ⅿ` が含まれ、ESP32用GCCが直接扱えないため、
付属スクリプトで一時的な英数字のドライブ名を割り当てます。処理後に割り当てを解除します。

```powershell
.\scripts\build.ps1
.\scripts\build.ps1 -Upload -Port COM11
& "$env:USERPROFILE\.platformio\penv\Scripts\platformio.exe" device monitor --port COM11
```

`COM11` は今回確認したポートです。接続先が変わった場合は `pio device list` で確認して置き換えます。
`-Port` を省略するとアップロード先を自動検出します。モニタ終了は `Ctrl+C` です。
英数字のみのパスでは通常の `pio run`、`pio run -t upload` も使用できます。

シリアル通信は115200bpsです。起動直後はコイルOFFで、入力するまで動きません。

| 入力 | 動作 |
| --- | --- |
| `1` / `2` | 操作対象のモータを選択（起動時はMotor 1） |
| `f` | 約1回転正転し、コイルOFF |
| `b` | 約1回転逆転し、コイルOFF |
| `r` | 連続正転 |
| `l` | 連続逆転 |
| `s` | 両モータを停止し、両方のIN1〜IN4をすべてLOWにする |

`f` / `b` / `r` / `l` は選択中のモータに作用します。
`1r` でMotor 1を連続正転、`2r` でMotor 2を連続正転します。
`1r2r` を送ると両方が連続正転し、`s` で両方を停止します。

大文字も使用できます。改行は無視します。不明な文字でヘルプを表示します。
新しい動作指令は選択中のモータの指令を置き換えます。もう一方のモータは動作を継続します。
`f` / `b` の途中でも `s` で停止できます。
停止してコイルをOFFにすると、モータは電気的な保持力を失います。

## 初回確認

1. 配線と共通GNDを確認して書き込み、シリアルモニタを開きます。
2. `1f` または `2f` を送信し、約8.2秒で約1回転分の指令が完了して `Done: coils off` が表示されることを確認します。
3. `b` で逆方向、`r` / `l` で連続回転、`s` で停止とコイルOFFを確認します。
4. `f` の途中でも `s` を送り、完了を待たずに停止することを確認します。

振動するだけの場合は、まずIN1〜IN4の接続順、5ピンコネクタ、外部5Vと共通GNDを確認します。
正転・逆転はこのコードで定義した方向です。

## 実装

`src/main.cpp` の `STEPS_PER_REV = 4096` と `STEP_INTERVAL_US = 2000` を使用します。
Motor 1が500µs間隔で振動のみとの報告を受け、切り分けのため2000µs間隔（約7.3rpm）に戻しています。
始動間隔も2000µsなので、現在は定速です。より短い間隔に設定した場合は1ステップごとに2µs短縮する加速処理が働きます。
実機で回転を維持できる最大速度は未確認です。
振動するだけ・回らない場合は `s` で停止し、ステップ間隔を長くして調整してください。
4096ハーフステップは仮の1回転で、正確な移動量は実機で校正してください。
8相のハーフステップを `micros()` で更新し、最後の相もその時点のステップ間隔だけ保持してからコイルをOFFにします。
時間カウンタの周回に対応し、処理が遅れた場合はステップをまとめて出力しません。

`HalfStepMotor` にピン・相・残りステップ数・タイミングをまとめています。
将来はモータごとにインスタンスを追加し、`loop()` で各 `update()` を呼び出せます。
現在は2インスタンスを同じ `loop()` 内で更新し、2台を制御します。Wi-Fi・BLE・XYZ制御は実装していません。

## PC上の制御ロジック検証

GCCのC++コンパイラがある場合、PowerShellで次を実行できます。

```powershell
New-Item -ItemType Directory -Force .pio | Out-Null
g++ -std=c++11 -Wall -Wextra -Werror -I tests/host tests/host/motor_test.cpp -o .pio/motor_host_test.exe
if ($LASTEXITCODE -eq 0) { & .\.pio\motor_host_test.exe }
```

GPIO出力と時計を模擬し、正逆の相順序、4096ステップ、最終相の保持、
途中停止、指令の置き換え、タイマー周回、加速と再始動、2台の独立動作と一括停止を確認します。
実機の回転確認は別途必要です。

### この環境での確認結果

- PC上の制御ロジックテスト：成功（GCC 13.2.0）。
- ESP32向けビルド：成功（2026-09-11、Espressif32 6.12.0）。RAM 21,520 bytes、Flash 270,505 bytes。
- 実機への書き込み：COM11のESP32-D0WD-V3へ成功、書き込みデータのハッシュ検証も成功。
- 115200bpsで起動メッセージと `s` への `STOP: coils off` 応答を確認済み。
- モータの回転は目視未確認です。回転指令の実行・完了はシリアル応答で確認しています。
- 低速に戻した後、Motor 2を停止したままMotor 1へ約1回転の指令を送り、完了応答を確認。終了後は両方停止・コイルOFFです。実際に回転したかは確認待ちです。
